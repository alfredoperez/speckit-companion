## Intent

A calm, readable walkthrough of SpecKit Companion in a real VS Code window. The viewer is the star: the sidebar with every spec's status, opening a spec, walking every document on the rail, a file link opening real code, tasks ticking, and above all the comment loop: write a note on a line, add it, see it on the spec, add a second, then Refine sends both to the assistant. Then the Overview, living specs, the four plan components, the workflow builder as coming next, and the Copilot app and Claude Code mod. Silent, captions only, slower than the 66-second tour so every screen can be read.

## Assets

All under `capture/assets/`, real recordings at 30fps with `*.events.json` click beats beside the tour films. Listed in `capture/extracted/asset-descriptions.md`.

## Customizations

- Show-it-as-is: the recordings are the video. Never rebuild UI.
- Screen Studio feel: on every click beat, a soft cursor dot moves to the click point and the camera pushes in toward it, then eases back.
- The comment chapter is the heart of the video and gets three frames, pushed in so the typed words read.
- Constellation look from `frame.md`, Specky only at the open and close.
- Silent: no music, no sound.

## Notes

- Zero em dashes in any on-screen text.
- The plan components are published; only the workflow builder is "coming next".
