Hover a line in the viewer, click the comment button and type your note. The card pins under that line as **Pending**. Press **Refine (N)** in the footer and every pending comment on that document goes to your assistant in one prompt.

It works the same on the spec, the plan and the task list, at any step.

## Comment on a line

You can comment on paragraphs, headings, list items, tasks, blockquotes, requirement rows and acceptance scenarios. Code blocks, tables and Mermaid diagrams take no comments, so comment on the heading or paragraph above them. A paragraph wrapped over several lines in the file counts as one line.

The composer offers a quick action that fills in suggested wording for the kind of line you're on, such as **Suggest removing task**. On a task line, **Toggle** flips the task's checkbox.

Expand a card to **Edit** or **Delete** it. Editing keeps the comment's place and status.

## Send the pending comments

**Refine (N)** shows in the footer once N comments are pending. **Refine** on any pending card does the same thing.

<p class="not-content"><img src={refine.src} width={Math.round(refine.width / 2)} height={Math.round(refine.height / 2)} alt="The viewer footer reading Next: Plan, with Regenerate, Plan and a Refine (1) button at the end." /></p>

The prompt covers the current document only, so comments on the plan don't ride along with the spec. For each comment it names the line and section, quotes the source text and gives your note, and it asks your assistant to edit the file in place.

The sent comments change to **Applied** and stay as history. Applied means sent, and nobody has checked the result. Read the change yourself, then comment again on anything missed.

## Where comments are kept

Comments are written to `.spec-context.json` in the spec's folder, so committing that file takes the review along with the branch. The viewer creates the file when the spec is first opened, and a comment can't be saved without it.

A comment follows its block of text and not a line number. If the block is edited away, the comment stays listed with its status in the Activity list under Run log on [the Overview](/docs/results/the-overview).

On a completed or archived spec the cards stay readable, and Refine, Edit and Delete are gone.
