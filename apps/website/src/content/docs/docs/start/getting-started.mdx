You will make one spec, watch it move through the workflow and read the record it leaves. Do [Install](/docs/install) first.

## Pick your path

| | Short path | Full path |
| --- | --- | --- |
| **Use it for** | A small change: up to 5 files and 10 tasks | A feature that touches more |
| **You run** | `specify`, then `implement` | `specify`, `plan`, `tasks`, then `implement` |
| **Or hands-off** | `/speckit.companion.auto` | `/speckit.companion.auto` |

The short path is built in to the SpecKit Companion workflow, and there is no setting to turn on. After it drafts the spec, `/speckit.companion.specify` sizes the change. A small one gets its plan and task list in that same pass, and the next step is implement. Anything bigger writes only the spec, and you continue with plan and tasks.

## Commands at a glance

Type these in your assistant's chat or terminal. Some assistants spell them with dashes, such as `/speckit-companion-plan`. They come from the Companion Spec Kit extension.

| Command | Use it when |
| --- | --- |
| `/speckit.companion.specify` | You have an idea. It writes the spec and sizes the change. |
| `/speckit.companion.plan` | The spec is ready and you want the design. |
| `/speckit.companion.tasks` | The plan is ready and you want a task list. |
| `/speckit.companion.implement` | The tasks are ready and you want them built. |
| `/speckit.companion.auto` | You want every step run for you, with no pauses. |
| `/speckit.companion.resume` | A run stopped and you want to continue where it left off. |
| `/speckit.companion.status` | You want to know the current step and what to do next. |
| `/speckit.companion.doctor` | A run looks wrong and you want a health report. |
| `/speckit.companion.mark-complete` | The work is finished and you want to close the spec. |

Living specs have seven more, all named `/speckit.companion.living-<verb>`. They are covered in [Living specs](/docs/discussions/living-specs).

## Good to know

SpecKit Companion hands your assistant the command text, then reads what lands on disk. It never reads the chat. The Overview's checks are a report of what the assistant said it ran, and nothing runs them again. Everything is plain files in your repo.
