SpecKit Companion puts your [Spec Kit](https://github.com/github/spec-kit) specs in front of you while your AI assistant works on them. You read each spec as a page, comment on its lines, send the next step with a button, and see what every run decided and checked.

## The two halves

| | VS Code extension | Companion extension for Spec Kit |
| --- | --- | --- |
| Installs into | Your editor | Your project, with `specify extension add` |
| Gives you | The [sidebar and viewer](/docs/navigate/viewer-and-sidebar), [line comments](/docs/steps/review-with-comments), and a button for each [step](/docs/steps) | A record of each run, the `/speckit.companion.*` [commands](/docs/reference/commands), [Auto](/docs/steps#auto) and [living specs](/docs/results/living-specs) |
| Without it | You run the commands yourself and read the markdown files | Stock Spec Kit commands, and [the Overview](/docs/results/the-overview) has no step times, decisions or checks to show |

Either half works alone. They only share the spec folder, so a spec made with one half opens fine in the other.

## One run

A run takes a feature request through specify, plan, tasks and implement, and the Companion workflow closes the spec for you at the end.

<WorkflowDiagram />

Companion hands your assistant the text of a command and then reads whatever lands on disk. It never reads the chat, and it gets no signal when the assistant finishes, so everything you see comes from files.

## Outside VS Code

The Companion extension for Spec Kit writes the same files wherever your assistant runs, and two other surfaces read them:

- [GitHub Copilot app](/docs/copilot-app): a board of every spec beside the chat, with a button for the next step.
- [Claude Code](/docs/claude-code): a line above the prompt and a pane with the steps and tasks, in your terminal.

## Start

[Install](/docs/install) it where you work, then follow the [Quickstart](/docs/start/your-first-spec) to your first spec. To change what a step does, open the [Workflow Builder](/docs/customize/workflow-builder). Every setting is in [Settings](/docs/reference/configuration).
