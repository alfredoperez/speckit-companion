If you run the Spec Kit commands in the Claude Code terminal, the SpecKit Companion mod keeps the run in view while you work. It reads the same run record as the VS Code viewer and the [Copilot app board](/docs/processes/copilot-app), so the three always agree on steps, times and task counts.

In a session that is already open, run `/reload-plugins` after installing.

<YouSee>

Run `/plugin`. The line under the tabs lists `speckit-companion` among the active mods.

</YouSee>

## What you get

| Part | What it shows |
| --- | --- |
| A band above the prompt | The spec you are following and where its run stands, such as `042-export-csv · Plan done · Tasks 7/12 · Implement running` |
| A pane beside the transcript | The four steps with the time each one took, the total active time, and the task list by phase with the task in flight marked. Tasks tick off as the agent finishes them. |

Step times follow the same rules as the viewer. A step ends at its own finish, the waits between steps count toward nothing, and the total is the time the steps were actually running.

## Switch specs with /spec

| You type | It does |
| --- | --- |
| `/spec` | Lists the most recent specs to pick from |
| `/spec 42` or `/spec export-csv` | Follows that spec |
| `/spec auto` | Goes back to following the latest one |

## Where it shows

| Where you run Claude Code | What you see |
| --- | --- |
| A terminal at least 144 columns wide | The band, and the pane beside the transcript by itself |
| A narrower terminal | The band. The pane waits until you run `/spec`, then sits above the prompt. |
| The Code tab of the Claude Desktop app | The band and the pane |
| The VS Code extension's chat panel, or `claude -p` | Nothing a mod draws. `/spec` answers in text: the spec you are following, its band line, and the recent specs. |

In VS Code itself, the SpecKit Companion extension already shows all of this.

## Good to know

The mod only reads. It never writes a spec file or sends a prompt, so you still run `/speckit-companion-plan`, `/speckit-implement` and the rest yourself.
