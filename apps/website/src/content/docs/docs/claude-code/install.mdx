---
title: Install the Claude Code mod
description: Add the SpecKit Companion mod to Claude Code with two commands, and check that it is active.
---

import CodeLine from '../../../../components/CodeLine.astro';
import Actions from '../../../../components/journey/Actions.astro';
import DocFigure from '../../../../components/journey/DocFigure.astro';
import YouSee from '../../../../components/journey/YouSee.astro';

<Actions>
  <CodeLine command="claude plugin marketplace add https://speckit-companion.dev/plugins/marketplace.json" />
  <CodeLine command="claude plugin install speckit-companion@speckit-companion" />
  <p>You need Claude Code 2.1.287 or later. Check with <code>claude --version</code>.</p>
</Actions>

If you run the Spec Kit commands in Claude Code, the mod keeps the run in view while you work. It shows the same steps, times and task counts as the VS Code viewer and the [Copilot app board](/docs/copilot-app/navigate-the-board).

<DocFigure
  src="live-mod-run.png"
  alt="The mod's pane during an implement run: Specify, Plan and Tasks ticked with their times, Implement running, the documents, and three of six tasks ticked."
  caption="The pane beside the transcript after installing: steps, documents and tasks for the spec you are working on."
/>

In a session that is already open, run `/reload-plugins` after installing.

<YouSee>

Run `/plugin`. The line under the tabs lists `speckit-companion` among the active mods.

</YouSee>
