---
title: Switch specs with /speckit-tracker
description: The /speckit-tracker command of the SpecKit Companion mod picks which spec the band and the pane follow in Claude Code.
---

The mod follows the latest spec until you tell it otherwise, and `/speckit-tracker` is how you tell it.

## What you can type

| You type | It does |
| --- | --- |
| `/speckit-tracker` | Lists the most recent specs to pick from |
| `/speckit-tracker 42` or `/speckit-tracker export-csv` | Follows that spec |
| `/speckit-tracker auto` | Goes back to following the latest one |

`/spec` still works as a shorter name for the same command.
