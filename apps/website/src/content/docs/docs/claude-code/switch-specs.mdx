---
title: Switch specs with /spec
description: The /spec command of the SpecKit Companion mod picks which spec the band and the pane follow in Claude Code.
---

The mod follows the latest spec until you tell it otherwise, and `/spec` is how you tell it.

## What you can type

| You type | It does |
| --- | --- |
| `/spec` | Lists the most recent specs to pick from |
| `/spec 42` or `/spec export-csv` | Follows that spec |
| `/spec auto` | Goes back to following the latest one |
