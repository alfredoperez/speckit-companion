If you work in the GitHub Copilot app, SpecKit Companion opens as a canvas beside your chat. It shows every spec in the repo, where each one is in the pipeline, and a button for the next step. You do not need the VS Code extension for it.

## Set it up

Copy the `apps/copilot-canvas` folder from the [repository](https://github.com/alfredoperez/speckit-companion/tree/main/apps/copilot-canvas) into your project or your user folder.

```bash
# shared with your team
cp -R apps/copilot-canvas <project>/.github/extensions/speckit-companion
# every project on your machine
cp -R apps/copilot-canvas ~/.copilot/extensions/speckit-companion
```

A project copy is code the app will not run until you accept it. Since version 1.1.26 of the Copilot app:

1. Commit the copy and open the project in the Copilot app.
2. Choose **Review repository content** on the notice the app shows (it is also in the project's settings under **Repository trust**), check that it lists `speckit-companion`, and choose **Accept for new sessions**.
3. Start a **new** session and ask: **Open the SpecKit Companion canvas**. It is also in the session's **+** menu under **Canvas**.

The session that was already open when you accepted never gets the board. If the agent opens an empty `speckit-companion.md` in the editor instead, you are in one of those: start another session.

| Where you copied it | When it shows up |
| --- | --- |
| Your user folder | In every new session, with nothing to accept. Not in a project that ships extensions you have not accepted, because the app turns every extension off there |
| The project | In sessions started after you accept the repository content, and only once the copy is on your default branch, because the Copilot app runs each session in a fresh worktree cut from that branch |

The app accepts the exact files under `.github/extensions/`. When any of them changes, such as after you update the board, the project's **Repository trust** shows **Update available** and new sessions lose the board until you accept again.

Use the user folder while you try it out.
