Two installs, through two channels: the VS Code extension from the Marketplace, and the Companion Spec Kit extension from the `specify` CLI. You need a folder open as a workspace, and Spec Kit 0.9.5 or newer for step 2.

## Updating

Re-run the step 3 command. The URL always serves the newest build and `--force` refreshes in place. In the editor, the Specs view **More Actions** menu has **Install Companion Extension**, and its **Upgrade…** submenu has **Update spec-kit Extension**. To silence the install nudges, set `speckit.companion.installPrompt` to `false`.

## When something didn't take

**`No such command 'extension'`.** You have the stock PyPI build. Redo step 2, then step 3.

**Stuck on an old build.** Run `specify extension remove companion`, then add it again.

**No `/speckit.companion.*` commands.** Run `specify extension list` from the repo root, not your home directory. Then reload the window so your provider re-reads its commands.

**No Living Specs view after step 3.** The install went somewhere other than this workspace.
