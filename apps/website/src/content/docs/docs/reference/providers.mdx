SpecKit Companion sends spec commands to the assistant you already use. Pick yours with **Settings > `speckit.aiProvider`** (default `claude`).

## How each one is reached

| Provider (`aiProvider` value) | Runs as |
| --- | --- |
| Claude Code (`claude`) | `claude` in a terminal |
| Claude Code (VS Code) (`claude-vscode`) | The Claude Code panel, no terminal |
| GitHub Copilot CLI (`copilot`) | `ghcs` / `gh copilot` in a terminal |
| Gemini CLI (`gemini`) | `gemini` in a terminal |
| Codex CLI (`codex`) | `codex` in a terminal |
| Qwen Code (`qwen`) | `qwen` in a terminal |
| OpenCode (`opencode`) | `opencode` in a terminal |
| IDE Chat (`ide-chat`) | Your editor's built-in chat (Copilot, Composer, Cascade) |
| Wibey CLI (`wibey`) | `wibey` in a terminal |
| Wibey (VS Code) (`wibey-vscode`) | The Wibey chat panel, no terminal |
| Antigravity (`antigravity`) | `agy` in an interactive terminal |

## What each one reads

Paths are relative to your project. IDE Chat owns none of these.

| Provider | Steering file | Steering folder | Agents | Skills | Hooks | MCP config |
|---|---|---|---|---|---|---|
| Claude Code, and in VS Code | `CLAUDE.md` | `.claude/steering/` | `.claude/agents/*.md` | `.claude/skills/` | `.claude/settings.json` | `.claude/settings.json` |
| GitHub Copilot CLI | `.github/copilot-instructions.md` | `.github/instructions/*.instructions.md` | `.github/agents/*.agent.md` | none | none | `.copilot/mcp-config.json` |
| Gemini CLI | `GEMINI.md` | none | none | none | none | `.gemini/settings.json` |
| Codex CLI | `AGENTS.md` | `.codex/` | none | `.agents/skills/` | none | `~/.codex/config.toml` |
| Qwen Code | `QWEN.md` | `.qwen/steering/` | none | none | none | `.qwen/settings.json` |
| OpenCode | `AGENTS.md` | none | `.opencode/agent/*.md` | none | none | `.opencode/opencode.jsonc` |
| Wibey, CLI and VS Code | `AGENTS.md` | none | `.wibey/agents/*.md` | `.wibey/skills/` | `.wibey/hooks/hooks.json` | `.wibey/.mcp.json` |
| Antigravity | `AGENTS.md` | none | none | none | none | none |

The Steering view reads user-level MCP config from your home folder at the same relative path. Permission behavior is a separate setting: see [Configuration](/docs/reference/configuration#permission-mode).

## IDE Chat

IDE Chat sends the prompt to your editor's chat instead of a terminal. The chat has to recognize `/speckit.*`, so run **SpecKit: Initialize Workspace** (`specify init`) first. When the workspace is initialized, the prompt is submitted. When it is not, the prompt is only prefilled, with a warning. Dispatch is one-way: nothing is read back.

![SpecKit Companion dispatching /speckit.plan into GitHub Copilot Chat in VS Code](https://raw.githubusercontent.com/alfredoperez/speckit-companion/main/docs/screenshots/copilot.png)

## Claude Code (VS Code)

This opens the Claude Code panel through its URI handler and prefills the command. The panel has no programmatic submit, so press Enter to run it. It shares the `.claude/` setup of the terminal provider. It needs the [Claude Code extension](https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code), and suggests terminal `claude` if it is missing.

![SpecKit Companion dispatching /speckit.implement into the Claude Code panel in VS Code](https://raw.githubusercontent.com/alfredoperez/speckit-companion/main/docs/screenshots/claude-vscode.png)
