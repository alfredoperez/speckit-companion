---
title: Telemetry
description: What the extension sends, what gates it, and what it never collects.
---

SpecKit Companion sends **anonymous, PII-free** usage events to PostHog, to help decide which AI providers and pipeline features to invest in. If **either** switch below is off, nothing is sent.

| Switch | Effect when off |
|--------|-----------------|
| `speckit.telemetry` (default `true`) | No extension telemetry, whatever the global setting says |
| VS Code's `telemetry.telemetryLevel` | No extension telemetry, whatever `speckit.telemetry` says |

## What is collected

| Signal | Value |
|--------|-------|
| AI provider selected | `claude`, `copilot`, `gemini`, ... |
| Workflow: default, and chosen at spec creation | `speckit`, `companion` or the literal `custom` |
| How the workflow was chosen | `default`, `picked` or `trial` |
| Phase dispatched | `specify`, `plan`, `tasks`, `implement` (or `custom`) |
| Spec created, completed, archived | Events. Completion counts once, from whichever path finished it. |
| Extension installed | A bare event, once ever per install |
| Every event carries | Extension version, VS Code version, platform |
| At activation | Spec Kit CLI version, spec count, whether the Companion Spec Kit extension is installed, and the on/off state of `defaultWorkflow`, `viewer.activityPanel`, `companion.installPrompt` and `telemetry` |
| Install prompt | `shown` or `clicked`, per surface |
| Specs panel visible, sample opened | Bare events, once per session |
| Spec opened, living spec opened | Bare events, once per item per session |
| Living-spec drift or sync run, steering doc opened | Bare events, per run or open |
| Identity | VS Code's random machine id. It is not derived from you. |

## What is never collected

Prompt content, file paths, spec names, capability names and custom workflow names. Only enum-like values, booleans, versions, counts and a random per-spec id.

The per-spec id is a random UUID stored in the spec's `.spec-context.json`. It links one spec's events into a funnel without revealing which spec it is.

A completion that happens while VS Code is closed goes unobserved.
