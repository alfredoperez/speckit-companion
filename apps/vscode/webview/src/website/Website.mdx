# The website

speckit-companion.dev is an Astro site and its components do not render in this Storybook. What it shares with the other surfaces is here; the rest is in the website folder.

- **Tokens**: `website/src/styles/tokens.css`, the Constellation sheet transcribed. Dark only. Ground `#0a0913`, accent `#a78bfa`, green `#7cc98a`. The capture palette *Constellation Violet* is anchored to it, and the figure frame's colours are transcribed from it.
- **Type**: Figtree for reading, JetBrains Mono for labels, Instrument Serif italic for one word per heading.
- **Wordmark**: `website/src/components/LogoMark.astro`, the small moss mascot inlined from `assets/icons/moss.svg` beside the name. The figure frame reads the same file and the Copilot board inlines a copy; `assets/icons/moss-16.svg` is the simplified cut for the favicon.
- **Mascot**: `website/public/mascot/`, fourteen poses at three sizes, built by `scripts/build-mascot-assets.mjs`.

See Core / Foundations for the swatches and specimens, and Core / Design for the rules.
