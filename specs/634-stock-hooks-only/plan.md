# Implementation Plan: Capture plain SpecKit runs with hooks only

**Feature**: [stock-hooks-only.spec.md](./stock-hooks-only.spec.md)

> **Scale note.** About 45 files across three areas: the spec-kit extension's preset, build tooling and docs; the VS Code extension's preset reconciler and Steering sidebar; and committed `specify init` fixtures. Most of it is deletion. Watch two things: the fixtures change only by running the `specify` CLI, and the reconciler flips from "keep the preset present" to "remove it once", so every test that pinned the old direction inverts.

## Summary

The `companion-standard` preset is deleted, with the golden files and parity checks that existed only for it. Plain SpecKit runs are captured by lifecycle hooks: the six that exist plus four "before" registrations of one new command, already written and benched on this branch. The VS Code extension stops installing the preset and removes a leftover install once, the same way it already removes three older presets.

The prompt text VS Code prepends needs no change. A stock command already gets the full stock preamble, chosen by the command's name, and that text never claimed the command body carries the protocol. A test pins it.
